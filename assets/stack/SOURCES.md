# Stack icon sources

These local 48 × 48 tiles identify technologies. Original logo paths are preserved; the tiles add a rounded frame and scale the artwork. They do not imply vendor endorsement.

Its [disclaimer](https://github.com/simple-icons/simple-icons/blob/4d29a35c954699b389a834aacc97dd6e7e74143c/DISCLAIMER.md) explains that brand artwork may have separate licenses and trademark rights. Its [icon metadata](https://github.com/simple-icons/simple-icons/blob/4d29a35c954699b389a834aacc97dd6e7e74143c/data/simple-icons.json) specifies Apache-2.0 for Apache Spark; a copy is included in `LICENSE-APACHE-2.0.txt`. Databricks and Temporal have no separate license declared in that metadata. Apache Spark is used to represent its Python API, PySpark; there is no invented PySpark logo. Temporal uses a white mark for contrast on the dark frame.
